# Lingerie Brand Manager

Десктопний застосунок для macOS (та інших платформ на Electron) з локальною базою даних SQLite для керування матеріалами, товарами, замовленнями та звітністю бренду білизни.

## Можливості
- 🔐 Авторизація з локальною таблицею користувачів (стандартний користувач: `admin@lingeriedashboard.app` / `admin123`).
- 📦 Управління матеріалами: пошук, фільтрація, CRUD, фото.
- 🛍️ Управління товарами: розрахунок собівартості та прибутку на основі матеріалів.
- 🧾 Управління замовленнями: генерація номерів, статуси, підрахунок сум.
- 📊 Аналітика: дашборд з доходами, трендами продажів, витратами, ТОП товарами.
- 💾 Дані зберігаються автоматично в локальній SQLite базі (`lingerie-manager.db`) у директорії користувача.
- 📂 Папка `~/Library/Application Support/Lingerie Brand Manager/` створюється автоматично під час першого запуску навіть у зібраному `.app`.

## Технології
- Electron + React + TypeScript
- Tailwind CSS для стилів
- better-sqlite3 для роботи з локальною БД
- Recharts для візуалізації

## Розробка

```bash
npm install
npm run dev
```

Команда `npm run dev` запускає одночасно процеси Electron та Vite для рендерера.

## Збірка

```bash
npm run build
```

Команда сформує фронтенд у `out/renderer/`, прелоад у `out/preload/` і головний процес у `out/main/`. Ці директорії використовуються під час подальшої упаковки під macOS.

## Запуск на macOS без терміналу

1. **Одноразово зібрати `.app` / `.dmg`.** На машині розробника виконайте `npm run package:mac`. Команда збере рендерер, а далі `electron-builder` покладе готові файли у папку `release/`.
2. **Відкрити DMG.** У Finder двічі клацніть на файл `release/LingerieBrandManager-<version>-<arch>.dmg` та перетягніть `Lingerie Brand Manager.app` у `Applications`.
3. **Запускати з Launchpad / Spotlight.** Після копіювання застосунок зʼявиться у списку програм і його можна відкривати подвійним кліком, без запуску терміналу.
4. **Оновлення.** Щоб отримати нову версію, повторіть кроки 1–2 та замініть застосунок у `Applications`.

> **Де зберігаються дані?** База `lingerie-manager.db` та налаштування зберігаються у `~/Library/Application Support/Lingerie Brand Manager/`. Вони автоматично переносяться при оновленні `.app`.

## Структура доступу
- Після першого запуску створюється база з дефолтним користувачем.
- Сесія зберігається в `localStorage`, дані у SQLite — автоматично при кожній операції.
